# #17 작업 로그 : SST 예외 의미 비교 / #17 work log : SST exception comparison

## 2026-10-08

- **기준선 재현**: 로컬 Linux x64 release로 #15 결과를 재현했다 — executed 1,592,800, mismatches 0, skipped_exception 150,304, boundary 8,701, quirk 6,892, unrepresentable 3.
- **범위 실측**: `EXCP` 150,304건을 벡터별로 집계했다(#GP 93,269, #UD 34,879, #SS 16,566, BOUND 1,858, #DE 1,009, INTO 232, INT3 104, 나머지는 `CD.MOO`의 INT n). #GP/#SS가 67 prefix 파일에 몰려 있어 `EA32` 오프셋과 대조했다. 오프셋 > 0xFFFF인 97,380건이 #GP/#SS였다. 이 대조로 #11의 'unreal 4GiB limit' 결론이 무효 SIB 테스트(`6784.MOO` #1076, 실제 EA 0x7C75) 하나에 기대고 있었다는 것이 드러났다. 업스트림 README도 limit 0xFFFF라고 밝힌다(설계 결정 1).
- **1차 구현(설계 결정 1~5)**: `FaultKind::kStackFault`, `Linearize`의 SS→#SS, CS limit에서 잘린 인출의 #GP(디코더에 `truncated`를 알려 주는 오버로드 추가), 하네스의 limit 0xFFFF·IVT 전달·벡터와 push된 FLAGS 비교. 결과는 executed 1,741,682, **mismatches 1,467**(31개 파일)이었다.
- **불일치 분석과 코어 수정**(설계 결정 6~9). 모두 코어가 SDM과 어긋난 곳이었다.
  - 정확한 폴트: POP m, LEAVE, ENTER, RET imm, RETF, IRET이 폴트할 때 바뀐 ESP/EBP를 그대로 남겼다. `Step`이 정수 상태를 저장해 두었다가 폴트면 복원한다(REP 문자열은 예외).
  - BT 계열을 피연산자 크기 단위로 접근하게 했다(24건). PUSHA는 낮은 슬롯부터 저장한다(7건). 32비트 POP sreg는 워드만 읽는다(210건). 이 세 가지와 정확한 폴트를 함께 적용해 1,467건이 275건으로 줄었다.
  - near 분기 목적지 마스크를 CS.D에서 피연산자 크기로 바꾸고, 분기 시점에 CS limit을 검사한다(`66C2/66C3` 262건). → 13건으로.
  - 남은 13건은 SDM과 다른 하드웨어 동작이다. POPA 부분 커밋 3건은 `skipped_hw_quirk`로 셌다. 처음에는 POPA의 #SS 전체를 quirk로 분류해 137건을 과하게 뺐고, 첫 슬롯 폴트는 비교 대상으로 되돌렸다. AAM 0의 SF/ZF/PF 10건은 그 세 플래그만 마스킹했다.
  - `C6 F8`/`C7 F8`(XABORT/XBEGIN으로 디코드됨) 6건이 미구현으로 남아 있었다. RTM ISA를 #UD로 처리했다.
- **검증**
  - **SST 실행 비교(최종)**: 941 파일 1,758,700 테스트 — **executed=1,741,900, passed=1,741,900, mismatches=0, delivered=149,100, skipped_unimplemented=0, skipped_exception=0**. 실행하지 않은 것: 경계 8,893(IN/INS 포트 입력 8,796, CLTS 97), 하드웨어 quirk 7,903(무효 SIB 7,894, IDIV 6, POPA 3), 표현 불가 4(a32 REP 중단 등).
  - SST 디코더 검증: decode_failures 0, length_mismatches 0(디코더 오버로드 추가 후에도 그대로).
  - 단위 테스트 8개 블록 추가(#SS/#GP 구분, POP m·LEAVE의 정확한 폴트, JMP/CALL 목적지의 CS limit, 잘린 인출 #GP, BT 단위 접근과 limit, PUSHAD 저장 순서와 ESP 보존, 32비트 POP DS, XBEGIN #UD). checks 370 failures 0.
  - 로컬 Linux x64 release·debug(경고를 오류로) 빌드와 `ctest` 통과. 나머지 호스트는 push 시 CI에서 확인한다.
- **문서**: README의 경고 상자와 달성도 표·현재 수치, ARCHITECTURE(정확한 폴트, `kStackFault`, SST 러너), analysis(unreal 정정, 예외 전달 실측, POPA·AAM 0 quirk), kb(EXCP의 flag_address), 가이드(`--execute` 절차와 집계 의미).
- **소비자 영향**: `FaultKind::kStackFault` 추가(설계 결정 2). 머지 뒤 rePIU·re2DJ 어댑터에 매핑을 추가하고 tag를 갱신하는 작업이 필요하다.
- **의미**: 정수 명령은 SST가 덮는 범위에서 예외 의미까지 맞는다. 1단계에 남은 것은 x87, 호스트 CPU 대조 fuzz, trace다.

*Baseline: #15's figures reproduced on a local Linux x64 release build. Scope: the 150,304 `EXCP` tests tallied by vector (#GP 93,269, #UD 34,879, #SS 16,566, BOUND 1,858, #DE 1,009, INTO 232, INT3 104, the rest `CD.MOO`'s INT n); the #GP/#SS concentration in the 67-prefixed files, checked against `EA32` offsets (97,380 above 0xFFFF recording #GP/#SS), showed that #11's 'unreal 4 GiB' conclusion rested on one invalid-SIB test (`6784.MOO` #1076, real EA 0x7C75) — upstream's README says 0xFFFF too (decision 1). First implementation (decisions 1–5: `kStackFault`, SS→#SS in `Linearize`, #GP for a fetch cut by the CS limit via a decoder overload reporting truncation, the harness's 0xFFFF limits, IVT delivery and the vector/pushed-FLAGS comparisons) gave 1,741,682 executed and **1,467 mismatches** in 31 files, every one a core departure from the SDM (decisions 6–9): precise faults — POP m, LEAVE, ENTER, RET imm, RETF and IRET left ESP/EBP changed, so `Step` now saves and restores the integer state on a fault, REP strings excepted — applied together with the BT family's operand-size access (24), PUSHA's lowest-slot-first stores (7) and the 32-bit POP sreg word read (210) took 1,467 down to 275; near branch targets masked by operand size instead of CS.D and checked against the CS limit at the branch (`66C2/66C3`, 262) took it to 13. The last 13 are hardware deviations: three POPA partial commits counted as `skipped_hw_quirk` (an over-broad first rule swallowed 137 first-slot faults and was narrowed back), and ten AAM 0 cases with only SF/ZF/PF masked; six `C6 F8`/`C7 F8` tests decoded as XABORT/XBEGIN were unimplemented until RTM became #UD. Verification: the final SST run over 941 files and 1,758,700 tests — **1,741,900 executed, 1,741,900 passed, zero mismatches, 149,100 delivered, zero unimplemented, zero exception skips**, leaving 8,893 boundaries (port input 8,796, CLTS 97), 7,903 hardware quirks (invalid SIB 7,894, IDIV 6, POPA 3) and 4 unrepresentable; the decoder validation unchanged (zero decode failures and length mismatches); eight new unit blocks, checks 370 failures 0; clean local Linux x64 release and debug (warnings as errors) builds with ctest, CI for the other hosts on push. Documents: README (warning box, attainment, current figures), ARCHITECTURE, the analysis topic (the 'unreal' correction, the delivery measurements, the POPA and AAM 0 quirks), the kb (EXCP's flag_address) and the guide (`--execute` and the counters). Consumer impact: `FaultKind::kStackFault`; after the merge, rePIU's and re2DJ's adapters need the mapping and a tag update. The integer set now matches including exception semantics as far as the suite reaches; phase 1 still needs x87, the host-CPU comparison fuzz and traces.*
