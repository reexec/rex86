# #21 작업 로그 : 최소 지원 사양을 대상 기판의 CPU로 재설정 / #21 work log : resetting the minimum specification to the target boards' CPUs

이슈: [#21](https://github.com/reexec/rex86/issues/21) | 설계: [20261008-i021](../design/20261008-i021-target-board-cpu-baseline.md) | 지시서: [20261008-i021](../work-orders/20261008-i021-target-board-cpu-baseline.md)

## 2026-10-08

- **출발점**: 정수 명령 호스트 대조 fuzz(다음 작업 #22)를 준비하던 중 사용자가 최소 지원 사양을 정했다. 안다미로 MK3, MK5와 EZ2DJ 1세대, 2세대 기판의 CPU를 지원하고, 사양이 목표와 다르면 재설정한다.
- **조사**: 원 문서 사이트(나무위키, Arcade Otaku wiki, GameRepair, EZ2 Wiki, Shiz arcade-docs, Wikipedia)가 이 환경의 네트워크 정책에서 모두 막혀, 웹 검색 결과의 발췌를 출처별로 교차 확인했다. MAME `src/mame/misc/ez2d.cpp`는 GitHub 원본을 직접 받아 주석을 읽었다. 결과:
  - MK3: Pentium II 333/366 MHz(Arcade Otaku)와 Celeron 333(실기 PC-Doctor 덤프, 갤러리 보고)으로 어긋나지만 둘 다 P6 + MMX다.
  - MK5: Tualatin Celeron 1.3 GHz, VIA 694T(나무위키 하나). Tualatin은 SSE가 있다.
  - EZ2DJ 1세대: AMD K6-2 300~400 MHz(클럭 표기는 출처마다 다름).
  - EZ2DJ 2세대: **미확정.** MAME는 EZ2Dancer 2nd Move(2001)를 ASUS CUBX + Celeron 533으로 적고 Socket 7 BIOS를 "원래 하드웨어?"로 남긴다. 다른 자료는 1st~6th를 K6-2로 묶는다.
- **결론**: 출처의 어긋남과 무관하게 명령 집합의 상한은 P6 정수 + P6 x87 + MMX + SSE(Pentium III)다. 지금 목표와의 차이는 다섯이다: 정수가 386 집합뿐(P6 추가 없음), MMX/SSE가 census 조건부, EFLAGS AC/ID가 386 동작, 성능 기준이 "Pentium II~III급", SSE2와 3DNow!의 지위가 없음.
- **성능 참고 측정**: 설계 결정 4에 넣으려고 scratchpad에서 Release 코어에 합성 루프 넷(정수, 메모리, call/ret, x87)을 돌렸다. 모두 약 3.5 MIPS(Intel Xeon 2.1 GHz)였고, callgrind로 본 시간 분포는 바이트 단위 인출과 페이지 검사 40%, Zydis 디코드 27%, `Step` 17%였다. 저장소에는 넣지 않았다(벤치마크 하네스는 별도 작업).
- **문서**: kb `target-board-cpus.md`와 색인, 설계, README 목표 1과 3, 경고 문단과 달성도 표(1단계 P6 정수 보완 행, 1b MMX/SSE 행), 헌장의 지원 CPU 사양 절, ARCHITECTURE의 `Features` 설명. 코드는 바꾸지 않았다.
- **검증**: 새로 넣은 상대 링크를 스크립트로 검사했다(아래). 빌드 변화가 없으므로 push 뒤 CI가 녹색인지만 확인한다.
- **남은 것**: EZ2DJ 2세대 CPU의 확정(기판 스펙표 또는 실기 덤프), K6-2를 흉내 낼 CMOV 플래그와 AC/ID(#22), MMX와 SSE(1b), 기판별 성능 수치(벤치마크 하네스 뒤).

*Starting point: while preparing the integer host-comparison fuzz (next task, #22), the user set the minimum specification: the CPUs of Andamiro's MK3 and MK5 and of the generation 1 and 2 EZ2DJ boards, with the targets reset where they differ. Research: every original site (NamuWiki, Arcade Otaku wiki, GameRepair, EZ2 Wiki, Shiz's arcade-docs, Wikipedia) is blocked by this environment's network policy, so web-search excerpts were cross-checked by source, and MAME's `src/mame/misc/ez2d.cpp` was fetched from GitHub and its comment read. Findings: MK3, Pentium II 333/366 (Arcade Otaku) against a Celeron 333 (a real board's PC-Doctor dump, a gallery report), both P6 + MMX; MK5, a 1.3 GHz Tualatin Celeron on a VIA 694T (one NamuWiki source), Tualatin having SSE; EZ2DJ generation 1, an AMD K6-2 at 300-400 MHz; generation 2 **unresolved** (MAME has the EZ2Dancer 2nd Move on an ASUS CUBX with a Celeron 533 and keeps a Socket 7 BIOS as "original HW?", other sources group 1st-6th as K6-2). Conclusion: whatever the sources disagree on, the ceiling is P6 integer + P6 x87 + MMX + SSE (Pentium III), differing from today's targets in five ways: integers stop at the 386 set, MMX/SSE are census-conditional, EFLAGS AC/ID behave as on a 386, performance says "Pentium II-III class", and SSE2 and 3DNow! have no status. Reference measurement for decision 4: four synthetic loops on a Release core in a scratchpad all ran at about 3.5 MIPS (Intel Xeon 2.1 GHz), callgrind putting 40% in byte-wise fetching with page checks, 27% in Zydis decoding and 17% in `Step`; nothing of it entered the repository (the benchmark harness is its own task). Documents: the kb page and index, the design, README goals 1 and 3 with the status note and the attainment table (a phase 1 P6 integer row, a phase 1b MMX/SSE row), the charter's supported CPU section and ARCHITECTURE's `Features` note; no code changed. Verification: the new relative links were checked by script (below); with no build change, CI need only stay green after the push. Remaining: settling the generation 2 EZ2DJ CPU (a board's spec label or a dump), the CMOV flag and AC/ID for emulating the K6-2 (#22), MMX and SSE (1b), and per-board performance numbers (after the benchmark harness).*

## 2026-10-08 (후속: 원문 확인 / follow-up: reading the originals)

- **출발점**: #22 머지 뒤 남은 작업을 정리하면서, 앞의 조사에서 막혔던 원문 사이트를 다른 환경(로컬 Windows 작업 환경)에서 다시 시도했다. 같은 날 v0.0.12 태그가 빠져 있어 squash 커밋 `f5ffdcb`에 로컬로 만들었다(push는 사용자).
- **받은 것**: 나무위키 「안다미로 Mk」, 「EZ2AC 시리즈/기체」와 dcinside는 원 사이트에서 직접 받았다. Shiz arcade-docs는 원 호스트가 DNS에 응답하지 않아 GitHub 미러 `shizmob/arcade-docs`(보관됨)의 `andamiro/board.md`, `andamiro/board/mkv.md`를 읽었다. Arcade Otaku는 Anubis 봇 검사에 막혀 Wayback 사본(2024-07-18)을 읽었다. EZ2 Wiki는 Cloudflare 526이라 Wayback 사본(2023-03-26)을 읽었지만 표 내용은 세대 구분과 연도만 남아 있었다. 받은 원문은 저장소에 넣지 않았다.
- **결과**:
  - MK3: Shiz의 실기 PC-Doctor 덤프가 "Intel Celeron 333", CPUID Family 6 Model 6 Stepping 5, L2 128 kB, 440BX다. Model 6과 L2 128 kB는 Mendocino Celeron이다. 나무위키는 Mendocino Celeron 366(SD)/400(DX) MHz와 440ZX다. Arcade Otaku의 Pentium II 333/366만 덤프와 맞지 않는다. **확인됨: Mendocino Celeron 333~400 MHz.**
  - MK5: 나무위키(Tualatin Celeron 1.3 GHz, VIA 694T)에 Shiz(Celeron 1 GHz 또는 1.3 GHz, VIA Apollo Pro133A 694X)가 더해져 출처가 둘이 됐다. 1 GHz 변형의 코어는 추정(Coppermine-128)이고 어느 쪽이든 SSE가 있고 SSE2가 없다.
  - EZ2DJ 1세대: 나무위키의 공식 기판 사양 절은 K6-2(Soltek SL-56D5)를 1st부터 6th TRAX까지(1999~2004) 적는다. 2nd TRAX의 업그레이드는 그래픽(TNT2 M64), 메모리(128 MB), OS(98 SE)뿐이다. EZ2 Wiki 사본은 "1st Gen PC (1999-2007) AMD K6"다.
  - EZ2DJ 2세대: **확정.** 나무위키는 Intel P6, Socket 370(VIA Apollo Pro 133A/133T), Pentium III Coppermine 533 MHz~1.0 GHz 또는 Tualatin Celeron 1.1~1.4 GHz를 7th TRAX부터 EZ2AC EVOLVE 2.03a까지(2007~2015) 적고, EZ2 Wiki 사본은 "2nd Gen PC (2007-2015)"다. 앞의 "Celeron 533"은 MAME `ez2d.cpp`가 적은 **EZ2Dancer 2nd Move** 기판이었고, 그 주석의 EZ2DJ 목록은 "이 하드웨어나 파생 하드웨어에서 돌았을 것으로 생각되는" 추정이었다.
- **결론**: 명령 집합의 상한(P6 정수 + P6 x87 + MMX + SSE)은 그대로다. 바뀐 것은 셋이다. (1) K6-2 흉내(`Features::cmov` 끔)의 대상이 EZ2DJ 1st~6th TRAX 전체이고, 3DNow! 판정도 그 census로 한다. (2) MK3의 기준 CPU는 Mendocino Celeron이다. (3) 가장 빠른 기판은 EZ2DJ 2세대(최대 1.4 GHz)다.
- **사용자 결정**: 기판에 CPU 변형이 여럿이면 성능 기준은 가장 빠른 변형으로 한다(A안). 그래서 실시간의 상한이 MK5의 1.3 GHz에서 EZ2DJ 2세대의 Tualatin 1.4 GHz로 바뀌었다.
- **문서**: kb `target-board-cpus.md`(출처와 확실성, 바로잡은 MAME 해석, 기판에서 명령 집합으로의 Mermaid 도식, 남은 미확정 절), 설계의 확인한 사양 표, 결정 1, 2, 4, README 목표 1과 3, 헌장의 지원 CPU 사양 절. 코드는 바꾸지 않았다.
- **검증**: 바뀐 문서의 상대 링크를 스크립트로 검사했다. 빌드 변화가 없으므로 push 뒤 CI가 녹색인지만 확인한다.
- **남은 것**: EZ2DJ 2세대의 실기 덤프(CPUID), MK5 1 GHz 변형의 코어, EZ2DJ 1세대 K6-2의 클럭 상한(성능 기준은 400 MHz로 둠).
