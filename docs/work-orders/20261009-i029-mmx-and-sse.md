# #29 작업 지시 : 1b — MMX와 SSE / #29 work order : phase 1b — MMX and SSE

이슈: [#29](https://github.com/reexec/rex86/issues/29) | 설계: [20261009-i029](../design/20261009-i029-mmx-and-sse.md) | 로그: [20261009-i029](../work-logs/20261009-i029-mmx-and-sse.md)

## 증분 1 / Increment 1

1. 공개 계약: `SseState`(`xmm`, `mxcsr`)와 `Reset()`, `FaultKind::kSimdFloatingPoint`, `Features::fxsr`, `mmx`/`sse`/`fxsr` 기본 켬(설계 결정 1). trace 형식의 `kFeatureFxsr`와 재생의 대응.
2. 기능 판정: SSE가 더한 MMX 정수 명령 목록, `FXSAVE`/`SSEMXCSR`/`SSE_PREFETCH` 집합(결정 2).
3. `src/interp/simd_access.{h,cpp}`: 64/128비트 피연산자, 정렬 검사, MM/XMM 접근, MMX 진입(TOP, 태그, 79:64, #MF)(결정 3, 4).
4. `src/interp/exec_fxsave.cpp`: FXSAVE/FXRSTOR, LDMXCSR/STMXCSR(결정 5).
5. `src/interp/exec_mmx.cpp`: MMX 전체와 SSE의 MMX 정수 명령, EMMS.
6. `src/interp/exec_sse.cpp`: SSE 이동, 논리, 셔플, 언팩, MOVMSKPS, MOVNTPS/MOVNTQ/MASKMOVQ, PREFETCHh, SFENCE.
7. 단위 테스트 `tests/unit/mmx_test.cpp`, `sse_test.cpp`. `interp_test.cpp`의 "미구현 명령" 예를 EMMS에서 다른 명령으로 바꾼다.
8. `tests/host/linux/simd_fuzz.cpp`와 CMake, ctest 짧은 실행(결정 7). Zen 3 x86-64와 i386 긴 실행 불일치 0.

## 증분 2 / Increment 2

9. 측정: 언더플로 판정 시점, #D와 #I의 우선순위, RCPPS/RSQRTPS의 특수값, CVT의 범위 밖과 NaN.
10. `src/fpu/sse_math.{h,cpp}`: binary32 위의 SSE 규칙(NaN, MIN/MAX, 예외 순서, #D, FTZ, 변환, 비교, RCP/RSQRT 모델)(결정 6).
11. `src/interp/exec_sse_float.cpp`: 패킹과 스칼라 산술, 비교, COMISS/UCOMISS, 변환, #XM.
12. 단위 테스트, fuzz의 허용치 판정, 긴 실행 불일치 0, trace 묶음 `tests/traces/simd.rxt`.

## 문서 / Documents

13. ARCHITECTURE(공개 계약, interp, fpu, 빌드 표), README 목표 1과 달성도, kb `simd.md`(MMX/SSE 배경)와 색인, 분석 `simd-host-comparison.md`와 색인, 가이드 `simd-host-fuzz.md`, 작업 로그. #21 kb의 기판 표에 `fxsr`를 반영한다.

*Increment 1: the contract (`SseState`, `kSimdFloatingPoint`, `Features::fxsr`, defaults on) with the trace format's `kFeatureFxsr`; feature gating (the SSE-added MMX integer list, the `FXSAVE`/`SSEMXCSR`/`SSE_PREFETCH` sets); `simd_access` (64/128-bit operands, alignment, MM/XMM access, MMX entry); `exec_fxsave.cpp` (FXSAVE/FXRSTOR, LDMXCSR/STMXCSR); `exec_mmx.cpp`; `exec_sse.cpp`; unit tests, moving `interp_test.cpp`'s unimplemented example off EMMS; the SIMD fuzz with a ctest run and long runs at zero mismatches on Zen 3 x86-64 and i386. Increment 2: measure tininess timing, #D/#I order, RCPPS/RSQRTPS special values and out-of-range/NaN conversions; `src/fpu/sse_math`; `exec_sse_float.cpp`; unit tests, the fuzz's tolerance, long runs at zero mismatches and the `tests/traces/simd.rxt` corpus. Documents: ARCHITECTURE, README goal 1 and attainment, kb `simd.md`, analysis `simd-host-comparison.md`, guide `simd-host-fuzz.md`, indexes, the work log, and `fxsr` in the #21 kb board table.*
