# rex86 v0.0.4

1단계의 첫 조각입니다. Zydis 디코더 모듈과 독립 명령 census 도구가 들어왔습니다. 공개 계약은 바뀌지 않았습니다.

## 변경 사항

- `third_party/zydis/`: Zydis v4.1.1 amalgamation(MIT, Zycore 포함) vendoring. rePIU가 다섯 호스트에서 검증한 것과 같은 파일이고 해시를 `THIRD_PARTY_NOTICES.md`에 기록했습니다. `rex86_zydis` STATIC 타깃, 경고 타깃 미적용.
- `src/decode/`: 코어 내부 디코더. 32비트 legacy 모드 고정 `Decoder`와 `DecodedInstruction`(길이, mnemonic, 피연산자 서명, x87 판별, 제어 흐름 분류, 직접 분기 목적지). Zydis 타입은 공개 헤더에 나타나지 않습니다.
- `src/tools/census/`: `rex86_census`. 평탄 코드 이미지와 명시적 진입점에서 재귀 하강 하한과 선형 스윕 상한, 서명 누적 커버리지, x87 집계를 보고합니다. Emscripten에서는 빌드하지 않습니다. 절차는 `docs/guides/instruction-census.md`.
- 단위 테스트 70개 추가(총 checks 183), `ARCHITECTURE.md`와 README 갱신.

## English

# rex86 v0.0.4

The first piece of phase 1: the Zydis decoder module and the standalone instruction census tool. The public contract is unchanged.

## Changes

- `third_party/zydis/`: the vendored Zydis v4.1.1 amalgamation (MIT, Zycore included) — the same files rePIU proved on five hosts, hashes recorded in `THIRD_PARTY_NOTICES.md`; the `rex86_zydis` STATIC target without the warnings target.
- `src/decode/`: the core-internal decoder — `Decoder` fixed to 32-bit legacy mode and `DecodedInstruction` (length, mnemonic, operand signature, x87, control-flow class, direct target). No Zydis type appears in a public header.
- `src/tools/census/`: `rex86_census`, reporting the recursive-descent lower bound, the linear-sweep upper bound, cumulative form coverage and the x87 tally over a flat code image from explicit entries; not built under Emscripten. Procedure in `docs/guides/instruction-census.md`.
- Seventy new unit checks (183 total), `ARCHITECTURE.md` and README updates.

## Resolved issues

- [#5](https://github.com/reexec/rex86/issues/5) The Zydis decoder and the standalone instruction census tool : PR #6

## Validation

- The local Windows x86 (MSVC `-A Win32`, VS 18, warnings as errors) Debug build and `ctest` pass 2 of 2 with checks 183 failures 0; `rex86_census` prints the designed report on a synthetic binary.
- The other four hosts are checked by CI on the branch push.
