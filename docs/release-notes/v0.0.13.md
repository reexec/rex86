# rex86 v0.0.13

문서만 바뀐 릴리스입니다. #21에서 막혔던 원문 출처를 다시 읽어 대상 기판의 CPU를 바로잡았습니다. EZ2DJ 2세대가 확정됐고, 성능 기준의 상한이 바뀌었습니다. 코드는 바뀌지 않았습니다.

## 변경 사항

- **원문 확인**: 나무위키는 원 사이트에서 직접 읽었습니다. Shiz arcade-docs는 GitHub 미러로, Arcade Otaku와 EZ2 Wiki는 Wayback 사본으로 읽었습니다.
- **MK3**: Mendocino Celeron 333~400 MHz입니다. 실기 PC-Doctor 덤프(CPUID Family 6 Model 6, L2 128 kB)로 확인했습니다.
- **MK5**: Celeron 1.0 또는 1.3 GHz입니다. 출처가 둘이 됐습니다.
- **EZ2DJ 1세대**: K6-2 기판의 게임은 1st부터 6th TRAX까지입니다.
- **EZ2DJ 2세대 확정**: Socket 370 P6(Coppermine Pentium III 533 MHz~1.0 GHz 또는 Tualatin Celeron 1.1~1.4 GHz)이고, 7th TRAX부터 EZ2AC EVOLVE까지입니다. 앞서 적은 "Celeron 533"은 MAME가 적은 EZ2Dancer 2nd Move 기판이었습니다.
- **성능 기준**: 기판에 CPU 변형이 여럿이면 가장 빠른 변형을 기준으로 합니다. 그래서 실시간 상한이 MK5의 1.3 GHz에서 EZ2DJ 2세대의 1.4 GHz로 바뀌었습니다.
- **문서**: kb `target-board-cpus.md`, #21 설계(결정 1, 2, 4), README 목표 1과 3, 헌장의 지원 CPU 사양 절, #21 작업 로그의 후속 절.

## 소비자 영향

- 공개 계약은 바뀌지 않았습니다.
- re2DJ: EZ2DJ 2nd~6th TRAX는 K6-2 기판의 게임입니다. 이 게임들을 흉내 낼 때는 `Features::cmov`를 끄고, CPUID도 K6-2로 답해야 합니다. 7th TRAX 이후는 P6 + MMX + SSE입니다.
- rePIU: MK3의 CPUID 응답은 Mendocino Celeron(Family 6 Model 6)이 실기와 맞습니다.

## English

# rex86 v0.0.13

A documentation-only release. The original sources blocked in #21 were read again and the target boards' CPUs corrected: generation 2 EZ2DJ is resolved, and the top of the performance reference moves. No code changed.

## Changes

- **Originals read**: NamuWiki directly from its site; Shiz's arcade-docs through its GitHub mirror; Arcade Otaku and EZ2 Wiki through Wayback copies.
- **MK3**: a Mendocino Celeron at 333-400 MHz, confirmed by a real board's PC-Doctor dump (CPUID family 6 model 6, 128 kB L2).
- **MK5**: a 1.0 or 1.3 GHz Celeron, now from two sources.
- **EZ2DJ generation 1**: the K6-2 board's games run from 1st through 6th TRAX.
- **EZ2DJ generation 2 resolved**: a Socket 370 P6 (a Coppermine Pentium III at 533 MHz-1.0 GHz or a Tualatin Celeron at 1.1-1.4 GHz), for 7th TRAX through EZ2AC EVOLVE. The earlier "Celeron 533" was MAME's EZ2Dancer 2nd Move board.
- **Performance reference**: where a board shipped with several CPU variants, the reference is the fastest one, so the real-time ceiling moves from the MK5's 1.3 GHz to generation 2 EZ2DJ's 1.4 GHz.
- **Documents**: the kb page `target-board-cpus.md`, the #21 design (decisions 1, 2 and 4), README goals 1 and 3, the charter's supported CPU section, and a follow-up section in the #21 work log.

## Consumer impact

- No contract change.
- re2DJ: EZ2DJ 2nd through 6th TRAX are K6-2 board games. Emulating them means `Features::cmov` off and K6-2 CPUID answers. 7th TRAX and later are P6 + MMX + SSE.
- rePIU: for the MK3, a Mendocino Celeron (family 6 model 6) CPUID answer matches the hardware.

## Resolved issues

- [#21](https://github.com/reexec/rex86/issues/21) Reset the minimum specification to the target boards' CPUs (follow-up) : PR #24

The previous release, v0.0.12, is squash commit `f5ffdcb`.
