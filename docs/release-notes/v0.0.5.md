# rex86 v0.0.5

소비자 프로젝트에 의존하지 않는 독립 검증 경로가 들어왔습니다. SingleStepTests/80386(MIT, 실제 386EX 하드웨어 생성) 러너가 디코더를 전체 스위트로 검증합니다. 공개 계약은 바뀌지 않았습니다.

## 변경 사항

- `src/tools/sst/`: MOO v1.1 사양 기반 자체 파서와 `rex86_sst` 러너(1차: 디코더 검증, `REX86_SST_DIR`로 ctest 등록, Emscripten 제외). 인터프리터가 생기면 같은 러너가 실행 비교로 확장됩니다.
- `src/decode/`: `Decoder::Mode { kLegacy32, kLegacy16 }`. real mode 스위트와 `Features::segments_16bit`의 디코드 쪽 선행 작업.
- 문서: 가이드 `docs/guides/singlesteptests.md`, 지식 기반 `docs/kb/singlesteptests-moo.md`, 후보 조사 기록(#7 설계: test386.asm은 GPLv3로 공식 경로 제외, DOOM 1.9 shareware와 CoreMark는 후속 후보).

## English

# rex86 v0.0.5

The consumer-independent validation path arrives: a SingleStepTests/80386 (MIT, generated on real 386EX hardware) runner validates the decoder across the full suite. The public contract is unchanged.

## Changes

- `src/tools/sst/`: a specification-based MOO v1.1 parser and the `rex86_sst` runner (stage 1: decoder validation; ctest hook via `REX86_SST_DIR`; not built under Emscripten). The same runner grows into execute-and-compare once the interpreter exists.
- `src/decode/`: `Decoder::Mode { kLegacy32, kLegacy16 }`, the groundwork for the real-mode suite and `Features::segments_16bit`.
- Documents: the guide, the MOO knowledge-base topic, and the candidate survey (design #7: test386.asm excluded as GPLv3; DOOM 1.9 shareware and CoreMark recorded as follow-up candidates).

## Resolved issues

- [#7](https://github.com/reexec/rex86/issues/7) The SingleStepTests/80386 independent validation runner (stage 1: decoder) : PR #8

## Validation

- The full suite, 941 files and 1,758,700 tests: `parse_failures=0 decode_failures=0 length_mismatches=0 expected_ud=34864` (decode refusals agreeing with the hardware's recorded #UD).
- Unit tests pass with checks 227 failures 0 (synthesized MOO parser tests and 16-bit decoder cases included); the local Windows x86 (MSVC, warnings as errors) build and `ctest` pass 2 of 2; the other four hosts are checked by CI on the branch push.
