# 릴리스 노트 / Release Notes

`v<version>.md` 한 파일이 한 릴리스다. 노트에는 변경 사항, 해결된 이슈 `#N`(제목)과 PR 번호, 검증한 구성을 적는다. squash 커밋 ID는 머지 뒤에야 생기므로 노트 파일에 미리 적지 않고, 다음 릴리스 노트나 GitHub Release 본문에서 보완한다(`AGENTS.md` 브랜치와 머지 규칙).

*One `v<version>.md` file per release, holding the changes, the resolved issues `#N` (with titles) and PR number, and the configurations verified. A squash commit's ID exists only after the merge, so it is not written in advance; the next release notes or the GitHub Release body supply it (see the branch and merge rules in `AGENTS.md`).*
