# rex86 v0.0.14

x87 2차 증분입니다. 초월함수 여덟 개(FSIN, FCOS, FSINCOS, FPTAN, FPATAN, F2XM1, FYL2X, FYL2XP1)를 구현해 1단계를 마쳤습니다.

## 변경 사항

- **초월함수**: 삼각함수는 x87 내부의 66비트 π 근사(`0.C90FDAA2 2168C234 C × 2²`, SDM 1권 8.3.8)로 인자를 정확히 줄이고, 그 뒤 참 함수값을 CW.RC 방향으로 64비트에 정확히 반올림합니다. 정밀도 제어는 적용되지 않습니다. 계산은 정수 연산과 SoftFloat의 binary128 급수만으로 하므로 모든 호스트에서 결과 비트가 같습니다.
- **SDM이 정하지 않은 동작**은 Intel Kaby Lake 실측을 따릅니다.
  - 2⁻⁶⁸보다 작은 인자에서 FSIN, FPTAN은 x를, FCOS는 1을 냅니다. #P를 세우고 C1 = 0입니다.
  - 정의역 밖: |x| > 1인 F2XM1은 x를 그대로 냅니다. x ≤ −1인 FYL2XP1은 y가 유한하면 x를, y가 ±0이나 ±∞이면 부호를 뒤집은 y를 냅니다.
  - C0와 C3는 바꾸지 않습니다.
  - 정확한 결과에도 #P를 세우고, 그 결과가 tiny이면 #U도 세웁니다.
  - 스택 폴트의 응답도 실측을 따릅니다.
- **새 파일**:
  - `src/fpu/`: `softfloat_bridge`(x87_math.cpp에서 분리), `wide_float`, `transcendental_kernels`, `x87_transcendental`.
  - `src/interp/`: `exec_x87_transcendental.cpp`.
  - `StackFault`와 `Commit`은 `x87_stack`으로 옮겼습니다.
- **x87 fuzz**: 여덟 명령을 대조에 넣었습니다.
  - 입력은 정의역에 가중을 둡니다.
  - 판정은 ulp 허용치입니다. RC가 nearest면 1 ulp, 다른 방향이면 2 ulp 이내, 또는 C1만 다른 경우를 허용합니다.
  - 새 옵션: `--only`(쉼표 목록), `--show-tolerance`, `--dump`.
- **오라클** `scripts/x87_transcendental_oracle.py`: Python `decimal`로 170자리에서 모델값을 계산해, 코어가 정확히 반올림하는지 독립적으로 확인합니다. 외부 패키지는 쓰지 않습니다.
- **trace 묶음**: `tests/traces/x87_transcendental.rxt`(1,850건)를 더했습니다.
- **문서**: #25 설계(구현 중 확정된 사항), 분석 `x87-host-comparison.md` 5절, kb `x87.md`의 초월함수 절, x87 fuzz 가이드, ARCHITECTURE, README 달성도(1단계 완료).

## English

# rex86 v0.0.14

x87 increment 2: the eight transcendentals (FSIN, FCOS, FSINCOS, FPTAN, FPATAN, F2XM1, FYL2X, FYL2XP1), completing phase 1.

## Changes

- **Transcendentals**: the trigonometric arguments are reduced exactly by the x87's internal 66-bit π (`0.C90FDAA2 2168C234 C × 2²`, SDM Vol. 1, 8.3.8). The true function value is then correctly rounded to 64 bits in CW.RC's direction; precision control does not apply. Integer arithmetic and SoftFloat binary128 series alone compute it, so every host gets the same bits.
- **Behavior the SDM leaves open** follows measurements on an Intel Kaby Lake:
  - Below 2⁻⁶⁸, FSIN and FPTAN return x and FCOS returns 1, with #P and C1 = 0.
  - Out of domain: F2XM1 with |x| > 1 returns x. FYL2XP1 with x ≤ −1 returns x for a finite y, and the sign-flipped y for a zero or infinite y.
  - C0 and C3 are left untouched.
  - Exact results still raise #P, and #U as well when tiny.
  - The stack-fault responses follow the measurements too.
- **New files**:
  - `src/fpu/`: `softfloat_bridge` (split out of x87_math.cpp), `wide_float`, `transcendental_kernels`, `x87_transcendental`.
  - `src/interp/`: `exec_x87_transcendental.cpp`.
  - `StackFault` and `Commit` moved to `x87_stack`.
- **x87 fuzz**: the eight join the comparison.
  - Inputs are weighted toward each instruction's domain.
  - Judging uses an ulp tolerance: within 1 ulp when RC is nearest, within 2 ulps otherwise, or C1 alone differing.
  - New options: `--only` (comma-separated list), `--show-tolerance`, `--dump`.
- **Oracle** `scripts/x87_transcendental_oracle.py`: computes the model with Python's `decimal` at 170 digits to check independently that the core rounds correctly. It uses no packages.
- **Trace corpus**: adds `tests/traces/x87_transcendental.rxt` (1,850 cases).
- **Documents**: the #25 design (settled during implementation), section 5 of the analysis `x87-host-comparison.md`, the transcendentals section of the kb page `x87.md`, the x87 fuzz guide, ARCHITECTURE and README attainment (phase 1 done).

## Consumer impact

- No contract change.
- The transcendentals produce results where they stopped with `kIllegalInstruction` before, so guest code that builds trigonometric tables or computes angles now runs on the core.
- Results differ from Intel hardware by at most an ulp, or in C1 alone.

## Validation

- Transcendental host comparison (Intel Core i5-7200U Kaby Lake, x86-64): 20M cases with **zero mismatches**. 6.88% were tolerated (301,731 differing in C1 alone, 1,074,784 by 1 ulp, none by 2 ulps).
- All 481 x87 forms: 12M cases with **zero mismatches**.
- i386 Debug transcendentals: 100,000 cases with zero mismatches.
- Oracle: on 60,259 computed-path cases, the core's results equal the correctly rounded value and C1 in every case.
- SingleStepTests: 1,741,900 executed, zero mismatches, zero unimplemented (as in v0.0.13).
- Unit tests at checks 539, failures 0. ctest passes on x86-64 Release, i386 Debug and GCC ASan/UBSan with `-Werror`. The three trace corpora replay with zero mismatches.
