# rex86 v0.0.9

인터프리터 3차 증분입니다. 세그먼트 적재, far 제어 흐름, BCD 등이 들어와 정수 명령이 SingleStepTests 범위에서 완결되었습니다(실행 159만 테스트 불일치 0, 미구현 0).

## 변경 사항

- `src/interp/exec_segments.cpp`: MOV/PUSH/POP sreg, LDS/LES/LFS/LGS/LSS, 같은 권한의 far JMP/CALL/RETF, IRET, WAIT, 특권 명령의 `kPrivilegedInstruction` 거절.
- `src/interp/exec_bcd.cpp`: AAA/AAS/DAA/DAS/AAM/AAD, BOUND(`kBound`), SALC.
- `src/interp/exec_strings.cpp`: INS/OUTS+REP. 호스트가 거절하면 retire 없이 재시작 가능하게 멈춤(`StepStatus::kStopped`).
- `access`: `LoadSegment` — 모든 선택자(null 포함)를 호스트에게 묻고 CS는 실행 가능, SS는 쓰기 가능을 요구.
- 인터럽트 shadow: MOV SS, POP SS, IF를 켠 STI 직후 한 경계는 외부 인터럽트 지연.
- SST 하네스: 포트 쓰기 수락(OUT/OUTS 비교), 특권 폴트와 `kStopped`는 경계로 분류.

## 소비자 영향

- `include/rex86/environment.h`: `LoadDescriptor`의 의미 구체화(주석). null 선택자에도 호출되며, 코드 선택자는 `executable=true`, 스택 선택자는 `writable=true`를 돌려줘야 한다. rePIU·re2DJ 어댑터는 2A/2B 단계에서 이 규칙대로 구현.
- `include/rex86/cpu.h`: private 멤버 `interrupt_shadow_` 추가. API 무변경, 재빌드만 필요.

## English

# rex86 v0.0.9

Interpreter increment 3: segment loads, far control flow, BCD and the rest complete the integer set as far as SingleStepTests reaches (1.59M executed tests, zero mismatches, zero unimplemented).

## Changes

- `src/interp/exec_segments.cpp`: MOV/PUSH/POP sreg, LDS/LES/LFS/LGS/LSS, same-privilege far JMP/CALL/RETF, IRET, WAIT, and the refusal of system instructions with `kPrivilegedInstruction`.
- `src/interp/exec_bcd.cpp`: AAA/AAS/DAA/DAS/AAM/AAD, BOUND (`kBound`), SALC.
- `src/interp/exec_strings.cpp`: INS/OUTS with REP, stopping restartably (`StepStatus::kStopped`) when the host declines.
- `access`: `LoadSegment` asks the host for every selector, null included, requiring an executable CS and a writable SS.
- The interrupt shadow after MOV SS, POP SS and an IF-enabling STI.
- SST harness: port writes accepted (OUT/OUTS comparable); privileged faults and `kStopped` classified as boundaries.

## Consumer impact

- `include/rex86/environment.h`: the `LoadDescriptor` meaning made concrete (comment) — called for null selectors too; code selectors must answer `executable=true`, stack selectors `writable=true`. rePIU's and re2DJ's adapters implement this in phases 2A/2B.
- `include/rex86/cpu.h`: the private member `interrupt_shadow_`. No API change; a rebuild suffices.
