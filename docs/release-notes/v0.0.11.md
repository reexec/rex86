# rex86 v0.0.11

x87 1차 증분입니다. Berkeley SoftFloat 3e를 바탕으로 80비트 x87(초월함수 제외)을 구현했습니다. 새로 만든 호스트 CPU 대조 fuzz로 4,000만 건을 비교해 불일치 0입니다.

## 변경 사항

- `third_party/softfloat/`: Berkeley SoftFloat Release 3e(`f74b1e4`, BSD 3-Clause)를 vendoring했습니다. template-FAST_INT64 소스와 8086 specialization은 수정하지 않았고, `platform.h`만 이 저장소의 파일입니다.
- `src/fpu/`: x87 수치 모델입니다. 피연산자 분류(무효 형식, pseudo-denormal), SDM 4.9.2 예외 우선순위, 마스크된 응답과 지수 조정 결과(OE/UE), C1 반올림 보고, FPREM/FPREM1(부분 감소 N = 32 + D mod 32), FSCALE, FXTRACT, BCD, 상수를 다룹니다.
- `src/interp/exec_x87*.cpp`: 초월함수를 뺀 x87 명령 전체를 구현했습니다. 레지스터 스택, 태그, FIP/FDP/FOP, 보호 모드 환경 이미지(16/32비트)를 다루고, 다음 대기형 명령에서 #MF를 보고합니다.
- `include/rex86/environment.h`: `FaultKind::kFloatingPoint`(#MF, 벡터 16)를 추가했습니다.
- `tests/host/linux/x87_fuzz.cpp`: 같은 기계어를 호스트 CPU와 코어에서 실행해 비교합니다. x86 Linux에서만 빌드되고 ctest에 짧은 실행이 등록됩니다. `--replay`로 한 건을 재현할 수 있습니다.
- SST 하네스: 다음 명령이 덮어써진 trailing HLT이면 가장 먼저 표현 불가로 분류합니다.
- 문서: analysis `x87-host-comparison.md`, kb `x87.md`, 가이드 `x87-host-fuzz.md`, THIRD_PARTY_NOTICES, ARCHITECTURE, README를 추가하거나 갱신했습니다.

## 소비자 영향

- `FaultKind`의 `kStackFault` 뒤에 `kFloatingPoint`가 추가되어 `kOther`의 정수값이 하나 밀렸습니다. 소스 빌드라 재빌드만 하면 됩니다. 두 어댑터는 새 값을 매핑해야 합니다. rePIU는 `kOther` 또는 DPMI 예외 16/IRQ13 경로로, re2DJ는 Win32 SEH의 `STATUS_FLOAT_*`로 매핑합니다.
- x87 명령이 이제 실행됩니다. 지금까지 `kIllegalInstruction`이던 x87 명령(초월함수 제외)이 실제 결과를 냅니다.

## 검증

- x87 호스트 CPU 대조(AMD Zen 3): 4,000만 건 **불일치 0**. SDM과 다른 호스트 동작 1종(마스크 안 된 #IA 비교, 251,332건)은 따로 셉니다.
- SingleStepTests: executed 1,741,900, mismatches 0, unimplemented 0(v0.0.10과 같음).
- 단위 테스트 checks 414 failures 0. 로컬 GCC release·debug, Clang debug(`-Werror`) 빌드를 통과했습니다. 나머지 호스트는 CI에서 확인합니다.

## English

# rex86 v0.0.11

x87 increment 1: an 80-bit x87 on Berkeley SoftFloat 3e, transcendentals excluded, with a new host-CPU comparison fuzz showing zero mismatches over 40M cases.

## Changes

- `third_party/softfloat/`: Berkeley SoftFloat Release 3e (`f74b1e4`, BSD 3-Clause), the template-FAST_INT64 sources and the 8086 specialization unmodified, with this repository's `platform.h`.
- `src/fpu/`: the x87 numeric model — operand classes (invalid encodings, pseudo-denormals), SDM 4.9.2 exception priority, masked responses and exponent-adjusted OE/UE results, the C1 round-up report, FPREM/FPREM1 (partial reduction N = 32 + D mod 32), FSCALE, FXTRACT, BCD and the constants.
- `src/interp/exec_x87*.cpp`: every x87 instruction but the transcendentals, with the register stack, tags, FIP/FDP/FOP, the protected-mode environment images (16/32-bit) and #MF at the next waiting instruction.
- `include/rex86/environment.h`: `FaultKind::kFloatingPoint` (#MF, vector 16).
- `tests/host/linux/x87_fuzz.cpp`: the same machine code on the host CPU and the core; x86 Linux only, a short run registered with ctest, `--replay` for one case.
- SST harness: an overwritten trailing HLT that execution falls through to is classified unrepresentable first.
- Documents: the analysis topic `x87-host-comparison.md`, the kb entry `x87.md`, the guide `x87-host-fuzz.md`, THIRD_PARTY_NOTICES, ARCHITECTURE and README.

## Consumer impact

- `FaultKind` gains `kFloatingPoint` after `kStackFault`, shifting `kOther`'s integer value; a rebuild suffices, and both adapters map the new value (rePIU: `kOther` or the DPMI exception 16 / IRQ13 path; re2DJ: Win32 SEH's `STATUS_FLOAT_*`).
- x87 instructions now execute: those that reported `kIllegalInstruction` (transcendentals aside) produce real results.

## Resolved issues

- [#19](https://github.com/reexec/rex86/issues/19) x87 increment 1 : PR #20

## Validation

- x87 host-CPU comparison (AMD Zen 3): 40M cases, **zero mismatches**; one host behavior deviating from the SDM (unmasked-#IA compares, 251,332 cases) counted apart.
- SingleStepTests: 1,741,900 executed, zero mismatches, zero unimplemented (as in v0.0.10).
- Unit tests at checks 414 failures 0; local GCC release/debug and Clang debug (`-Werror`) builds; CI checks the other hosts.
