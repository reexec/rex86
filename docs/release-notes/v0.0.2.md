# rex86 v0.0.2

첫 릴리스입니다. rePIU와 re2DJ가 호스트 CPU가 x86이 아닌 환경(브라우저의 WebAssembly, ARM 기기)에서 원본 32비트 x86 코드를 실행하기 위해 함께 쓸 IA-32 사용자 모드 CPU 코어의 저장소, 규칙, 공개 계약을 세웠습니다. 실행 엔진은 아직 없습니다.

## 변경 사항

- 개발 규칙(`AGENTS.md`): rePIU 규칙의 CPU 코어 부분집합. 작업 처리와 GitHub issue 연동, 브랜치와 머지 절차, 코어 경계 규칙, 소비자 규칙.
- 공개 계약(`include/rex86/`): `CpuState`(80비트 x87, Intel SDM 초기값), `GuestMemory`와 페이지 속성표, `Environment`와 `CodeCacheServices`와 `Event`, `Cpu`(게이트, 인터럽트 라인, `Run`). `Run`은 엔진이 없음을 `kNoEngine`으로 명시적으로 보고합니다.
- 검증: 단위 테스트 113개, `rex86_probe`, 다섯 호스트 CI(Windows x86, Linux x64 GCC와 Clang, Linux i386, Linux AArch64, wasm32).
- 문서: 프로젝트 헌장, 코딩 스타일, 아키텍처, #1 설계와 작업 지시서와 작업 로그.

## 검증

- Linux x64 GCC 13 Debug와 Clang 18 Release를 `-Werror`로 빌드, `ctest` 2/2 통과.
- GitHub Actions run 1(`c930055`)에서 여섯 작업 통과. `rex86_probe` 출력은 포인터 폭(x64와 arm64는 8, i386과 wasm32는 4)만 빼고 모든 호스트에서 같습니다.

## 알려진 것

- 실행 엔진이 없습니다. 인터프리터, 디코더, 80비트 x87, census 도구, 호스트 CPU 대조는 다음 작업입니다.
- `main`의 첫 커밋(bootstrap)은 브랜치의 base가 필요해 `main`에 직접 두었습니다. 저장소 생성 때 한 번뿐인 예외입니다.

## English

# rex86 v0.0.2

The first release. It sets up the repository, rules and public contract of the IA-32 user-mode CPU core that rePIU and re2DJ will share to run original 32-bit x86 code on hosts whose CPU is not x86 (WebAssembly in a browser, ARM devices). There is no execution engine yet.

## Changes

- Development rules (`AGENTS.md`): the CPU-core subset of rePIU's rules, with task handling and GitHub issue integration, the branch and merge procedure, core boundary rules and consumer rules.
- The public contract (`include/rex86/`): `CpuState` (80-bit x87, Intel SDM reset values), `GuestMemory` with its page attribute table, `Environment`, `CodeCacheServices` and `Event`, and `Cpu` (gates, the interrupt line, `Run`). `Run` reports the absence of an engine explicitly as `kNoEngine`.
- Verification: 113 unit checks, `rex86_probe`, CI on five hosts (Windows x86, Linux x64 GCC and Clang, Linux i386, Linux AArch64, wasm32).
- Documents: the project charter, coding style, architecture, and the #1 design, work order and work log.

## Resolved issues

- [#1](https://github.com/reexec/rex86/issues/1) Repository structure, development rules and the shared CPU core's public contract : PR [#2](https://github.com/reexec/rex86/pull/2)

## Validation

- Linux x64 GCC 13 Debug and Clang 18 Release build with `-Werror`; `ctest` passes 2 of 2.
- GitHub Actions run 1 (`c930055`) passes all six jobs; `rex86_probe` prints the same lines on every host apart from pointer width (8 on x64 and arm64, 4 on i386 and wasm32).

## Known

- No execution engine. The interpreter, decoder, 80-bit x87, census tool and host-CPU comparison are the next tasks.
- The first commit on `main` (the bootstrap) was placed on `main` directly because the branch needed a base; a one-time exception at repository creation.
