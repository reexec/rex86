인터프리터가 들어왔습니다. 실행 코어와 정수 명령 핵심 그룹이 SingleStepTests 실행 비교를 불일치 0으로 통과합니다. 공개 계약 헤더는 바뀌지 않았습니다.

## 변경 사항

- `src/interp/`: `interp::Step`(한 명령 실행), 주소 생성·세그먼테이션 폴트·`kTranslated` store 검사(`access`), 폭별 즉시 계산 플래그(`flags.h`). 1차 명령 그룹: MOV 계열, ALU 계열, 스택, near 제어 흐름, 플래그·폭 변환, 경계 명령(HLT, INT n, 포트 I/O, RDTSC, CPUID). 범위 밖 명령은 `kIllegalInstruction` 폴트.
- `src/cpu.cpp`: `Run`이 실행 루프(게이트, 인터럽트 전달, 예산, 정지 요청), `ActiveEngine`은 `kInterpreter`. `rex86_probe` 둘째 줄은 `engine=interpreter run=fault`(리셋 상태의 페이지는 비매핑).
- `rex86_sst --execute`: 초기 상태 적용 → 주입된 HLT retire까지 실행 → RM32 마스크 하 비교. 미구현·예외·호스트 경계·하드웨어 quirk을 분리 집계.
- `docs/analysis/singlesteptests-386ex-deviations.md`: 386EX 실측 사실(SIB scale-on-base quirk, POPAD ESP 이미지 적재, SMM EFLAGS 상위 비트, 0x3E notrack/DS override 차이).

## English

# rex86 v0.0.7

The interpreter arrives: the execution core and the core integer groups pass the SingleStepTests execute-and-compare with zero mismatches. The public contract headers are unchanged.

## Changes

- `src/interp/`: `interp::Step`, address generation with segmentation faults and the `kTranslated` store check, eager width-parametric flags; the first groups (moves, ALU, stack, near control flow, flag/width conversion, the host boundaries). Out-of-scope instructions fault with `kIllegalInstruction`.
- `src/cpu.cpp`: `Run` is the execution loop (gates, interrupt delivery, budget, stop requests) and `ActiveEngine` answers `kInterpreter`; `rex86_probe`'s second line reads `engine=interpreter run=fault` (reset-state pages are unmapped).
- `rex86_sst --execute`: apply the initial state, run until the injected HLT retires, compare under the RM32 masks, with unimplemented/exception/boundary/quirk skips counted apart.
- `docs/analysis/singlesteptests-386ex-deviations.md`: facts measured from the 386EX (the SIB scale-on-base quirk, POPAD's ESP image load, the SMM EFLAGS upper bits, the 0x3E notrack/DS-override difference).
