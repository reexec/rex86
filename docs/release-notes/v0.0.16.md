# rex86 v0.0.16

1b단계입니다. MMX와 Pentium III의 SSE(FXSAVE/FXRSTOR, MXCSR 예외 포함)를 구현해, 대상 기판 CPU의 상한(P6 정수, P6 x87, MMX, SSE)을 모두 갖췄습니다.

## 변경 사항

- **MMX**: 모든 MMX 명령과 SSE가 더한 MMX 정수 명령(PSHUFW, PAVGB/W, PEXTRW, PINSRW, PMAXSW, PMAXUB, PMINSW, PMINUB, PMULHUW, PSADBW, PMOVMSKB, MASKMOVQ, MOVNTQ)을 구현했습니다.
  - MM 레지스터는 x87 물리 레지스터의 하위 64비트입니다.
  - MMX 명령은 TOP을 0으로, 태그를 모두 유효로 만들고, 쓴 레지스터의 비트 79:64를 FFFF로 씁니다.
  - EMMS는 태그를 비우고 TOP도 0으로 만듭니다.
  - 대기 중인 x87 예외가 있으면 #MF를 냅니다.
- **SSE**:
  - 이동, 논리, 셔플, 언팩, MOVMSKPS, 비시간 저장, PREFETCHh, SFENCE를 구현했습니다.
  - 부동소수점 산술, MIN/MAX, SQRT, RCP/RSQRT, CMPPS/CMPSS, COMISS/UCOMISS, 변환을 구현했습니다.
  - 16바이트 정렬을 요구하는 형태는 정렬이 어긋나면 #GP입니다.
- **SSE 부동소수점 모델** `src/fpu/sse_math`: SoftFloat binary32 위에 SSE 고유의 규칙을 얹었습니다. SDM이 침묵하는 곳은 AMD Zen 3 실측을 따랐습니다.
  - 언더플로는 반올림 전에 판정합니다(x87과 다름).
  - NaN이 둘이면 첫 피연산자를 냅니다.
  - NaN, #I, #Z가 있는 요소에서는 #D를 세우지 않습니다.
  - FZ를 지원합니다. DAZ는 Pentium III에 없으므로 쓰면 #GP입니다.
  - 마스크 안 된 예외는 SDM 11.5.1 순서대로 #XM을 내고 결과를 쓰지 않습니다.
  - RCP/RSQRT는 결정적인 모델입니다. 결과가 모든 호스트에서 같습니다.
- **FXSAVE/FXRSTOR, LDMXCSR/STMXCSR**: Pentium III의 MXCSR(유효 비트 0xFFBF)을 따릅니다. SSE가 꺼져 있으면 FXSAVE는 MXCSR과 XMM 영역을 건드리지 않습니다.
- **공개 계약**:
  - `CpuState::sse`(`xmm[8]`, `mxcsr`)가 생겼습니다.
  - `FaultKind::kSimdFloatingPoint`(#XM)가 더해졌습니다.
  - `Features::fxsr`가 더해졌습니다.
  - `mmx`, `fxsr`, `sse`가 기본으로 켜집니다.
- **SIMD 호스트 대조 fuzz** `rex86_simd_fuzz`: FXRSTOR와 FXSAVE 사이의 명령 하나를 호스트와 코어에서 비교합니다. 호스트의 폴트는 신호로 받습니다. trace 묶음 `tests/traces/simd.rxt`를 더했습니다.
- **SST 러너**는 386EX처럼 MMX, SSE, FXSAVE를 끈 채 돕니다.
- **문서**:
  - #29 설계, 지시서, 작업 로그.
  - kb `simd.md`, 분석 `simd-host-comparison.md`, 가이드 `simd-host-fuzz.md`.
  - ARCHITECTURE, README(경고문, 1b 완료, 현재 수치), 대상 기판 kb의 기판별 `Features`.

## 소비자 영향

- **`CpuState`가 커졌습니다.** 어댑터는 `sse.xmm`과 `sse.mxcsr`을 옮겨야 합니다. re2DJ의 guest SEH `CONTEXT::ExtendedRegisters`(FXSAVE 이미지)가 이 필드로 변환됩니다.
- **`FaultKind::kSimdFloatingPoint`** 매핑을 더해야 합니다. 게스트가 MXCSR의 마스크를 풀지 않으면 생기지 않습니다.
- **기본값이 바뀌었습니다.** `Features{}`를 그대로 쓰면 이제 MMX/SSE/FXSAVE가 실행됩니다(전에는 #UD). 기판별로 끄는 플래그는 다음과 같고, CPUID 응답과도 맞춰야 합니다.
  - MK3: `sse = false`.
  - K6-2(EZ2DJ 1세대): `fxsr = false`, `sse = false`, `cmov = false`.

## English

# rex86 v0.0.16

Phase 1b: MMX and the Pentium III's SSE (FXSAVE/FXRSTOR and MXCSR exceptions included), completing the target boards' CPU ceiling (P6 integer, P6 x87, MMX, SSE).

## Changes

- **MMX**: every MMX instruction and the MMX integer instructions SSE added (PSHUFW, PAVGB/W, PEXTRW, PINSRW, PMAXSW, PMAXUB, PMINSW, PMINUB, PMULHUW, PSADBW, PMOVMSKB, MASKMOVQ, MOVNTQ).
  - The MM registers are the low 64 bits of the x87 physical registers.
  - An MMX instruction sets TOP to 0 and every tag to valid, and writes FFFF into bits 79:64 of the register it writes.
  - EMMS empties the tags and zeroes TOP too.
  - A pending x87 exception raises #MF.
- **SSE**:
  - Moves, logic, shuffles, unpacks, MOVMSKPS, non-temporal stores, PREFETCHh and SFENCE.
  - Floating-point arithmetic, MIN/MAX, SQRT, RCP/RSQRT, CMPPS/CMPSS, COMISS/UCOMISS and the conversions.
  - Forms that need 16-byte alignment raise #GP when misaligned.
- **The SSE floating-point model** `src/fpu/sse_math`: SSE's own rules on SoftFloat binary32. Where the SDM is silent it follows measurements on an AMD Zen 3.
  - Tininess is detected before rounding (unlike the x87).
  - With two NaNs, the first operand comes back.
  - No #D in a lane with a NaN, #I or #Z.
  - FZ is supported. DAZ is absent on the Pentium III, so setting it is #GP.
  - Unmasked exceptions raise #XM in SDM 11.5.1's order, writing nothing.
  - RCP/RSQRT use a deterministic model, the same on every host.
- **FXSAVE/FXRSTOR, LDMXCSR/STMXCSR**: the Pentium III's MXCSR (valid bits 0xFFBF). With SSE off, FXSAVE leaves the MXCSR and XMM fields alone.
- **Public contract**:
  - Adds `CpuState::sse` (`xmm[8]`, `mxcsr`).
  - Adds `FaultKind::kSimdFloatingPoint` (#XM).
  - Adds `Features::fxsr`.
  - `mmx`, `fxsr` and `sse` default to on.
- **The SIMD host-comparison fuzz** `rex86_simd_fuzz`: one instruction between FXRSTOR and FXSAVE on the host and the core, with host faults caught as signals. Adds the trace corpus `tests/traces/simd.rxt`.
- **The SST runner** keeps MMX, SSE and FXSAVE off, as on the 386EX.
- **Documents**:
  - The #29 design, work order and work log.
  - The kb page `simd.md`, the analysis `simd-host-comparison.md` and the guide `simd-host-fuzz.md`.
  - ARCHITECTURE, README (status note, 1b done, current figures) and the per-board `Features` in the target-board kb.

## Consumer impact

- **`CpuState` grew.** Adapters carry `sse.xmm` and `sse.mxcsr`. re2DJ's guest SEH `CONTEXT::ExtendedRegisters` (an FXSAVE image) converts through them.
- **Map `FaultKind::kSimdFloatingPoint`.** It never occurs unless a guest unmasks MXCSR exceptions.
- **The defaults changed.** `Features{}` as is now executes MMX/SSE/FXSAVE, which raised #UD before. Turn these off per board, consistent with the CPUID answers:
  - MK3: `sse = false`.
  - K6-2 (EZ2DJ generation 1): `fxsr = false`, `sse = false`, `cmov = false`.
