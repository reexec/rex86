# rex86 v0.0.31

웹 데모의 첫 실기기 측정을 기록했습니다([#62](https://github.com/reexec/rex86/issues/62)). 코드는 바뀌지 않았습니다.

## 변경 사항

- **실기기 기록**: Android 16의 Chrome 154에서 배터리로 v0.0.30 데모를 돌린 보고 줄을 [브라우저 wasm 분석](../analysis/browser-wasm.md) 5.1절과 #62 작업 로그에 적었습니다.

## 발견

- `mixed`, wasm 엔진으로 7,968프레임(약 80억 단계)을 돌려 바퀴 11,075개가 모두 참조 모델과 맞았습니다. 모바일 브라우저에서 처음 확인한 정확성 증거입니다.
- 처리량은 최근 1초 33.4 MIPS입니다. 400 MHz 기판 기준 실시간 비율은 0.083, 1.4 GHz 기판은 0.024입니다. 데스크톱 Chromium(AMD Ryzen 5 5600X, `rex86_bench` 60.5 MIPS)의 약 0.55배인데, 재는 방법이 달라 추정 비교로 둡니다.
- 코어 모듈 539 KiB, wasm 힙 16.4 MiB, 엔진 메모리 4.61 MiB(블록 54, 모듈 46)입니다.
- 미확정: 기기 모델, 같은 기기의 측정 모드와 인터프리터 값, 전원 연결 시의 값, iOS Safari. 목표 7의 수치 상한은 iOS Safari 값이 모인 뒤 정합니다.

# rex86 v0.0.31

Records the web demo's first real-device measurement (#62); no code changes.

## Changes

- **Real-device record**: the report lines of the v0.0.30 demo run in Chrome 154 on Android 16, on battery, go into section 5.1 of the browser wasm analysis and the #62 work log.

## Findings

- `mixed` on the wasm engine ran 7,968 frames (about 8 billion steps) with all 11,075 laps matching the reference model, the first correctness evidence on a mobile browser.
- Throughput is 33.4 MIPS over the last second, a real-time ratio of 0.083 against the 400 MHz boards and 0.024 against the 1.4 GHz board. That is about 0.55 times desktop Chromium (AMD Ryzen 5 5600X, `rex86_bench` 60.5 MIPS), kept as an inferred comparison because the methods differ.
- The core module is 539 KiB, the wasm heap 16.4 MiB and engine memory 4.61 MiB (54 blocks, 46 modules).
- Unresolved: the device model, the same device's measurement-mode and interpreter figures, figures on power, and iOS Safari; goal 7's numeric caps wait for iOS Safari's figures.

## The previous release's campaign (v0.0.30)

Run 38386037305: **success**, all 12 jobs passing.
