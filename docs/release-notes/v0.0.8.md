# rex86 v0.0.8

인터프리터 2차 증분입니다. 시프트/회전, 곱셈/나눗셈, 문자열+REP, 비트 연산이 들어왔고 SingleStepTests 실행 비교가 146만 테스트에서 불일치 0입니다. 공개 계약은 바뀌지 않았습니다.

## 변경 사항

- `src/interp/exec_arith.cpp`: 시프트/회전(RCL/RCR 포함), SHLD/SHRD, MUL/IMUL/DIV/IDIV(`kDivide` 폴트), BT/BTS/BTR/BTC(메모리 비트 베이스), BSF/BSR, SETcc, ENTER/LEAVE, XLAT.
- `src/interp/exec_strings.cpp`: MOVS/STOS/LODS/SCAS/CMPS와 REP/REPE/REPNE.
- `rex86_sst`: RM32/f_umask 극성 확정(비트 1 = 정의된 비트), `80386.csv`의 `f_umask` 로드, 표현 불가 테스트와 하드웨어 quirk 분리 집계.
- SDM 미정의 영역의 386 실측값 반영(시프트 count>폭의 CF, 16비트 SHLD/SHRD count>16) — `docs/analysis/singlesteptests-386ex-deviations.md` 2b절.
- 버그 수정: 문자열 소스의 ES override 무시, 32비트 SHLD carry의 64비트 시프트 미정의 동작.

## English

# rex86 v0.0.8

Interpreter increment 2: shifts/rotates, multiply/divide, strings with REP and the bit operations, with the SingleStepTests execute-and-compare at zero mismatches over 1.46 million tests. The public contract is unchanged.

## Changes

- `src/interp/exec_arith.cpp`: shifts/rotates (RCL/RCR included), SHLD/SHRD, MUL/IMUL/DIV/IDIV (`kDivide` fault), the BT family with the memory bit base, BSF/BSR, SETcc, ENTER/LEAVE, XLAT.
- `src/interp/exec_strings.cpp`: MOVS/STOS/LODS/SCAS/CMPS with REP/REPE/REPNE.
- `rex86_sst`: the RM32/f_umask polarity pinned down (a set bit marks a defined bit), `80386.csv`'s `f_umask` loaded, unrepresentable tests and hardware quirks counted apart.
- Measured 386 values adopted where the SDM says undefined (shift CF above the width, 16-bit SHLD/SHRD above count 16) — analysis section 2b.
- Fixes: the string source ignoring an ES override, and an undefined 64-bit shift in the 32-bit SHLD carry.
