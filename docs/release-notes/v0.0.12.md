# rex86 v0.0.12

최소 지원 사양을 대상 기판(안다미로 MK3, MK5, EZ2DJ 1, 2세대)의 CPU에 맞춰 P6 정수 + P6 x87 + MMX + SSE로 재설정하고(#21), 그중 P6 정수 명령을 구현했습니다(#22). 32비트 정수 명령을 i386 호스트 CPU와 대조하는 fuzz, 다섯 호스트에서 재생되는 trace 형식과 묶음, ASan/UBSan CI 작업도 함께 들어왔습니다.

## 변경 사항

- **최소 사양 재설정(#21)**: kb `target-board-cpus.md`(기판별 CPU, 출처와 확실도), 설계, README 목표 1과 3, 프로젝트 헌장의 지원 CPU 사양 절. SSE2 이후는 범위 밖이고, 3DNow!는 EZ2DJ 1세대 census가 사용을 확인할 때만 넣습니다.
- **P6 정수(#22)**: `src/interp/exec_post386.cpp`에 CMOVcc, BSWAP, XADD, CMPXCHG, CMPXCHG8B를, UD0/UD1/UD2는 #UD로 구현했습니다. `Features::cmov`(기본 켬)가 CMOVcc와, x87이 켜져 있으면 FCOMI 계열과 FCMOVcc를 함께 켜고 끕니다. POPF와 IRET이 EFLAGS의 AC와 ID를 씁니다.
- **trace**: `src/trace/`(형식과 `trace::Replay`, 내부 라이브러리 `rex86_trace_format`)와 재생 도구 `rex86_trace`(`--dump N`). `tests/traces/`의 고정 시드 묶음 14,587건(정수 12,000, x87 2,587)을 ctest `rex86_trace_corpus`가 모든 호스트에서 재생합니다.
- **정수 호스트 대조 fuzz** `rex86_int_fuzz`: i386 Linux 프로세스에서 트랩 플래그로 명령 하나를 실행해 같은 게스트 주소의 코어와 비교합니다. 형태 1,112개(149개 mnemonic). `--record`, `--failures`, `--stats`, `--only`. x87 fuzz에도 `--record`가 생겼습니다.
- **fuzz가 드러낸 코어 수정**: 읽기 전용 세그먼트(CS override)로 쓰기는 #GP이고 읽고 쓰는 목적지는 읽기 전에 검사합니다. 접근 위반의 폴트 주소는 처음 닿지 못하는 바이트(CR2)입니다. ENTER는 최종 ESP에 쓰기를 시험하고 display를 스택 크기로 복사합니다. CMPS는 ES:(E)DI를 먼저 읽고, BOUND는 하한을 상한보다 먼저 비교합니다. XADD [m], r의 주소 재계산 버그를 고쳤고, PAUSE는 NOP입니다.
- **x87**: x rem ∞와 0배 FSCALE은 denormal ST(0)를 #U 없이 그대로 돌려줍니다(SDM 표와 Intel). #19가 따른 AMD의 응답은 x87 fuzz가 제조사 이탈로 셉니다.
- **빌드와 CI**: `REX86_SANITIZE`, CI 작업 `linux-x64-sanitize`(GCC ASan/UBSan), `linux-x86-debug` 프리셋의 C 컴파일러 `-m32`, `.gitattributes`의 `*.rxt binary`.
- **문서**: 분석 `integer-host-comparison.md`(새로), `x87-host-comparison.md`(Intel 결과), kb `trap-flag-single-step.md`, 가이드 `integer-host-fuzz-and-traces.md`, ARCHITECTURE, README.

## 소비자 영향

- `Features`에 `cmov`가 생겼습니다(기본 켬, 지금까지의 동작). K6-2 기판을 흉내 내는 소비자만 끕니다. 위치가 `x87` 바로 뒤라 집합 초기화로 `Features`를 만드는 코드는 확인이 필요합니다.
- POPF가 AC와 ID를 바꿉니다. 게스트의 CPU 판별이 486 이후와 CPUID 지원으로 보게 되므로, `Environment::Cpuid`의 응답이 흉내 내는 기판과 맞아야 합니다.
- CMOVcc 등 P6 정수 명령이 `kIllegalInstruction` 대신 결과를 냅니다.
- CS override로 쓰는 게스트는 이제 #GP를 받습니다(실제 CPU와 같음). 쓰기 가능한 코드 세그먼트가 필요한 소비자(실모드 등)는 `Descriptor::writable`을 켜야 합니다.
- `Event::fault_address`는 페이지를 넘는 접근에서 접근 시작 주소가 아니라 처음 닿지 못하는 바이트를 보고합니다.

## English

# rex86 v0.0.12

The minimum specification is reset to the target boards' CPUs (Andamiro MK3 and MK5, EZ2DJ generations 1 and 2), P6 integer + P6 x87 + MMX + SSE (#21), and the P6 integer part is implemented (#22), along with a fuzz comparing 32-bit integer instructions against an i386 host CPU, a trace format with a corpus replayed on all five hosts, and an ASan/UBSan CI job.

## Changes

- **Minimum specification (#21)**: the kb page `target-board-cpus.md` (each board's CPU, sources and confidence), the design, README goals 1 and 3 and the charter's supported CPU section; SSE2 and later are out of scope, 3DNow! enters only if a generation 1 EZ2DJ census shows its use.
- **P6 integer (#22)**: CMOVcc, BSWAP, XADD, CMPXCHG and CMPXCHG8B in `src/interp/exec_post386.cpp`, UD0/UD1/UD2 as #UD; `Features::cmov` (on by default) gates CMOVcc and, with x87 on, the FCOMI family and FCMOVcc; POPF and IRET write EFLAGS AC and ID.
- **Traces**: `src/trace/` (the format and `trace::Replay`, the internal `rex86_trace_format` library) and the `rex86_trace` tool (`--dump N`); a fixed-seed corpus of 14,587 cases (12,000 integer, 2,587 x87) in `tests/traces/`, replayed by ctest `rex86_trace_corpus` on every host.
- **Integer host-comparison fuzz** `rex86_int_fuzz`: one instruction under the trap flag in an i386 Linux process against the core at the same guest addresses, 1,112 forms (149 mnemonics), with `--record`, `--failures`, `--stats` and `--only`; the x87 fuzz gains `--record`.
- **Core fixes the fuzz found**: writes through read-only segments (CS overrides) are #GP, checked before the read of a read-modify-write destination; access violations report the first unreachable byte (CR2); ENTER probes the final ESP and copies the display at the stack width; CMPS reads ES:(E)DI first and BOUND compares the lower bound before the upper; XADD [m], r no longer recomputes its address; PAUSE is a NOP.
- **x87**: x rem ∞ and FSCALE by zero return a denormal ST(0) unchanged without #U (the SDM tables, Intel); AMD's response, which #19 followed, counts as a vendor deviation in the x87 fuzz.
- **Build and CI**: `REX86_SANITIZE`, the `linux-x64-sanitize` job (GCC ASan/UBSan), `-m32` for C in the `linux-x86-debug` preset, `*.rxt binary` in `.gitattributes`.
- **Documents**: the analysis topics `integer-host-comparison.md` (new) and `x87-host-comparison.md` (the Intel results), the kb page `trap-flag-single-step.md`, the guide `integer-host-fuzz-and-traces.md`, ARCHITECTURE and README.

## Consumer impact

- `Features` gains `cmov` (on by default, the behavior so far), switched off only to emulate the K6-2 board; it sits right after `x87`, so code building `Features` by aggregate initialization needs a look.
- POPF changes AC and ID, so guest CPU detection sees a 486-or-later with CPUID, and `Environment::Cpuid` must answer as the emulated board.
- CMOVcc and the other P6 integer instructions produce results instead of `kIllegalInstruction`.
- Guests writing through a CS override now get #GP, as on real CPUs; consumers needing a writable code segment (real mode, for instance) set `Descriptor::writable`.
- `Event::fault_address` reports the first unreachable byte of a page-straddling access rather than its start.

- Integer host comparison (Intel Xeon Cascade Lake, i386 process): 10M cases on the final binary, **zero mismatches**; 50,000 cases on the CI's AMD EPYC 7763, zero mismatches.
- x87 host comparison (Intel Xeon Cascade Lake): 20M cases, **zero mismatches**, 125,452 vendor deviations (unmasked-#IA compares) counted apart.
- SingleStepTests: 1,741,900 executed, zero mismatches, zero unimplemented (as in v0.0.11, also under ASan/UBSan).
- The 14,587-case corpus: zero mismatches on all five CI hosts and the local builds.
- Unit tests at checks 454 failures 0; local GCC Debug (sanitizers) and Release, Clang 18 Debug (`-Werror`), GCC i386 Debug and Release; all seven CI jobs green.
