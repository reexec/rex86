# rex86 v0.0.10

SingleStepTests의 예외 기록 테스트(15만 건)를 real mode IVT 전달 흉내로 비교 대상에 넣었습니다. 그 과정에서 드러난 코어의 SDM 이탈을 고쳤습니다. 실행 174만 테스트에서 불일치 0, 미구현 0입니다.

## 변경 사항

- `rex86_sst`: 세그먼트 limit을 real mode 기본값 0xFFFF로 바꿨습니다(#11의 'unreal 4GiB' 결론 정정). 폴트와 INT n/INT3/INTO를 IVT로 전달해 핸들러의 HLT까지 실행하고, 벡터와 push된 FLAGS 이미지(`flag_address`)를 비교합니다.
- `include/rex86/environment.h`: `FaultKind::kStackFault`를 추가했습니다. SS를 통한 limit 위반은 #SS입니다.
- `interp::Step`: 폴트는 정확합니다. 실행 전 정수 상태(GPR, EFLAGS, 세그먼트)를 저장했다가 폴트면 복원하고, REP 문자열만 완료된 반복을 유지합니다.
- near 분기 목적지를 CS.D가 아니라 피연산자 크기로 자르고, 분기 시점에 CS limit을 검사합니다. CS limit에서 잘린 명령 인출은 #GP입니다.
- BT/BTS/BTR/BTC의 메모리 접근을 피연산자 크기 단위로 바꿨습니다(SDM).
- 386 실측을 채택했습니다. PUSHA는 낮은 슬롯부터 저장하고, 32비트 POP sreg는 선택자 워드만 읽습니다. RTM(XBEGIN/XABORT)은 #UD입니다.
- README의 현재 상태와 달성도, ARCHITECTURE, analysis(예외 전달 실측, POPA·AAM 0 quirk), kb, SST 가이드를 갱신했습니다.

## 소비자 영향

- `FaultKind`에 `kStackFault`가 `kGeneralProtection` 바로 뒤에 추가되어 `kOther`의 정수값이 하나 밀렸습니다. 소스 빌드라 재빌드만 하면 됩니다. 두 어댑터는 새 값을 매핑해야 합니다. rePIU는 DPMI 예외 12 또는 GP 경로, re2DJ는 GP 경로입니다(평탄 SS에서는 발생하지 않음).
- 폴트 시 레지스터가 명령 전 값으로 복원됩니다. 소비자가 폴트 이벤트에서 보는 상태가 SDM 그대로입니다.

## English

# rex86 v0.0.10

The SingleStepTests exception tests (150,000) become comparable through emulated real-mode IVT delivery, and the core's departures from the SDM the comparison exposed are fixed: 1.74M executed tests, zero mismatches, zero unimplemented.

## Changes

- `rex86_sst`: real-mode default segment limit 0xFFFF (correcting #11's 'unreal 4 GiB' conclusion); faults and INT n/INT3/INTO delivered through the IVT and run to the handler's HLT, comparing the vector and the pushed FLAGS image (`flag_address`).
- `include/rex86/environment.h`: `FaultKind::kStackFault` — a limit violation through SS is #SS.
- `interp::Step`: precise faults — the integer state (GPRs, EFLAGS, segments) is restored on a fault, REP strings keeping completed iterations.
- Near branch targets truncated by operand size rather than CS.D and checked against the CS limit at the branch; a fetch cut by the CS limit is #GP.
- BT/BTS/BTR/BTC access one operand-size unit of memory (SDM).
- Measured 386 behavior adopted: PUSHA stores from the lowest slot up, a 32-bit POP sreg reads only the selector word; RTM (XBEGIN/XABORT) is #UD.
- README status and attainment, ARCHITECTURE, the analysis topic (delivery measurements, POPA and AAM 0 quirks), the kb and the SST guide updated.

## Consumer impact

- `FaultKind` gains `kStackFault` right after `kGeneralProtection`, shifting `kOther`'s integer value; consumers build from source, so a rebuild suffices, and both adapters map the new value (rePIU: DPMI exception 12 or its GP path; re2DJ: its GP path — a flat SS never raises it).
- Registers come back to their pre-instruction values on a fault, so the state a consumer sees at a fault event is the SDM's.
